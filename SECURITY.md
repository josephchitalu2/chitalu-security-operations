# Security reporting

Report routine defects through repository issues using redacted or fictional data. For sensitive vulnerabilities use GitHub private reporting if available, or contact the maintainer through [the portfolio](https://josephchitalu2.github.io/) before sharing confidential evidence. Do not include passwords, tokens, customer records, live malware or private captures in public issues.

Security behavior and release status are documented in the README. No guaranteed response time or bounty is offered.
